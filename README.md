# Calendar_Task_App

A calendar and task management mobile app built with React Native and Expo. Bottom-tab
navigation across a home view, a task list and a date selection screen.

## Stack

React Native, Expo, React Navigation (bottom tabs), react-native-vector-icons.

## Running it

```bash
npm install
npx expo start
```

Then open it in Expo Go, or in an Android/iOS simulator.
